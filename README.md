# Python Practical Programs

This repository contains 25 Python programs prepared for college practical work. Each program is saved in a separate file, so it is easy to find, run, understand, and practise one topic at a time.

## Requirements

- Python 3.8 or later
- No extra packages are needed for programs 1–24.
- Program 25 uses Python's built-in `turtle` module and needs a desktop environment that can open a graphics window.

## How to run

1. Download or clone this repository.
2. Open the folder in VS Code or a terminal.
3. Run the program you want to practise.

For example:

```bash
python 01_distance_between_two_points.py
```

On Windows, if `python` is not recognised, you can use the Python launcher:

```bash
py 01_distance_between_two_points.py
```

## Notes

- Programs that use binary search expect the input numbers to be in **ascending order**.
- The factorial programs accept non-negative whole numbers. Factorial is not defined for negative numbers or fractional values.
- The character-count program counts spaces and punctuation as characters too.
- The programs use simple input and output so they can be tested easily during practical sessions.

## Purpose

These programs are a practice collection for learning Python fundamentals, loops, conditions, strings, dictionaries, functions, recursion, searching, object-oriented programming, exception handling, and basic graphics.
